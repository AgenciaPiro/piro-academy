# Web pública — primera versión

Nuxt 4, SSR y prerender de tres rutas. Ejecutar con Node 22: `npm install`, `npm run dev`, `npm run build`, `npm run generate`. No hay backend ni recogida de datos. El logo tipográfico es provisional: sustituir por el PNG original aprobado (preferiblemente variante blanca para cabecera oscura). Los enlaces a empresas y campus requieren que sus servicios existan. No hay matrícula abierta.

Preproducción: noindex,nofollow intencional. Pendientes de lanzamiento: logo original, revisión visual y móvil, build reproducible con lockfile, datos legales y privacidad, canal de contacto verificado, revisión editorial y SEO, canonical/sitemap/robots, HTTPS y comprobación de subdominios. No desplegar como web definitiva hasta superar estos controles.

Referencia de arquitectura consultada: AgenciaPiro/PMP mdd/manuales/manual-stack.md (blob 950db3374a74dde1c11d2558b3b880d6b85e6a49). Modelo y guía de identidad definitivos pendientes de coordinación del monorepo.
